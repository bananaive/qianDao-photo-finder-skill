# 2026 Qiandao Lake race photo finder

Find rider photos from the 2026 Qiandao Lake (千岛湖) cycling race. Return a small set with source links, evidence, and confirmation status.

**Required input: `live_album_url`.** Use the event photo livestream link supplied in the current request or already provided for this task. If it is missing, ask for it before retrieving photos. No album URL is bundled. Check that it points to the 2026 Qiandao Lake race; use the main race-day category (shown as `11.8正赛日` on the event album) when the user asks for race photos. Interpret local capture times in `Asia/Shanghai` when the source confirms they are local times. Keep participant details, reference photos, and private exports local to the task.

1. **Define the search.** Use the requested album category, any time window, bib, stable gear, and preferred composition. Separate required traits from optional ones, and distinguish a confirmed photo from a reference that merely shows the gear. Treat the user's rejected photos as explicit exclusions. Ask for a missing detail only if it would change the search.
2. **Obtain and verify the index.** Use an authorized export, documented API, or supported browser access. Record a stable photo ID, capture time with timezone, and a photo page link when available. Compare the same category across snapshots with [diff_album.py](scripts/diff_album.py); verify completeness and a stable collection version before declaring no changes. A banner saying “new photos” or an unchanged total alone cannot establish the delta. See [manifest and update checks](references/manifests.md).
3. **Find a reliable seed.** Try an exact bib match against a readable copy, then inspect the actual bib. Calibrate OCR against a known readable example at the intended image size; a failed read is weak evidence, especially in thumbnails. Use [scan-bibs.swift](scripts/scan-bibs.swift) for local OCR on macOS, or an equivalent available OCR tool. A clear different bib on the same rider rules out a candidate. A missing or obscured bib does not.
4. **Match the same rider's gear.** Start with the strongest confirmed photos and inspect nearby captures by the same photographer, timestamp, and file sequence. Treat adjacency as a lead, then verify each frame. For a larger set, locate riders and compare tight regions of equipment or clothing. Use [rank_gear.py](scripts/rank_gear.py) with local gear crops if suitable. Score optional traits as supporting evidence. Compare equipment appearance without using facial identity. Review [the screening and output guide](references/review.md) before batch ranking or presenting results.
5. **Review and deliver.** Apply the requested composition rule, including whether to skip back views, occlusions, or background appearances. Verify crop matches against the full photo, especially in groups. Report confirmed photos separately from unconfirmed candidates, and name any coverage gaps. Save requested full-size copies under original filenames (resolve name collisions with the photo ID) and keep their source links. Never label a published full-size image as an untouched camera original unless verified.
